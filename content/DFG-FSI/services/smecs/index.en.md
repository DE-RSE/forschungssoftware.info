## Service description

> SMECS facilitates the creation and curation of research software metadata by extracting metadata from GitHub and GitLab repositories or importing existing metadata. It provides a user-friendly graphical interface for reviewing, editing, and completing the metadata without unnecessarily re-entering information already available elsewhere. SMECS supports extraction, visualization and curation based on CodeMeta, ERSmeta, and ConnOSS metadata schema. The curated metadata are exported as CodeMeta-compliant and ConnOSS-aligned JSON, supporting integration with other tools and the discoverability and reuse of research software.
