## Target audience

Researchers, research software engineers, metadata curators, repository maintainers, and metadata aggregators who need to generate standardized, machine-actionable metadata for research software hosted on GitHub, GitLab, or Codeberg.

## Service description
>
> CoMET-RS (Code Metadata Extraction Toolkit for Research Software) is a tool that automatically extracts metadata from code repositories and transforms it into FAIR, machine-actionable metadata (JSON-LD), supporting multiple schemas (e.g. ConnOSS, maSMP, CODEMETA) and multiple access channels including a CLI, a Python library, and a web API.
