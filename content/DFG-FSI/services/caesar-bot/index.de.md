## Zielgruppe

Entwickelnde und Nutzende von Forschungssoftware, die mit GitHub Issues arbeiten.

## Servicebeschreibung
> Der [CAES³AR Bot](https://gitlab.git.nrw/rpdm/projects-and-services/caesar/caesar-bot) ermöglicht kollaborativen Support für wissenschaftliche Open-Source Softwareprojekte. Es ist eine GitHub App, die auf unserer [Testseite](https://caesar-testpage.tools.web.gateway.ionos.coscine.dev/) ausprobiert werden kann. Aktuell beinhaltet die Funktionalität hauptsächlich das Starten von [Issue2Docker](../../services/issue2docker) und GitHub Actions zum Testen der Reproduzierbarkeit. Das Ziel ist es, die unterschiedlichen CAES³AR Features zu orchestrieren und den Supportprozess zu optimieren.
